# LaTeX theme for Markdeep v2

## Introduction

This is a simple code migration of the [Markdeep latex theme](https://morgan3d.github.io/markdeep/latest/latex.css), which is currently not capable for [Markdeep 2.0](https://github.com/morgan3d/markdeep/releases/tag/2.00).

So, I use DeepSeek-v4.1-Flash-1017 to vibe-coding this new `latex-theme-v2.js`, and add a simple citation feature (see `bib-citation.js`). This theme also adds a simple style (see `addon-style.css`).

## Usage

To use it, download this repository, and mmodify the file `example.md.html`.
