# LaTeX theme for Markdeep v2

## Introduction

This is a simple code migration of the [Markdeep latex theme](https://morgan3d.github.io/markdeep/latest/latex.css), which is currently not capable for [Markdeep 2.0](https://github.com/morgan3d/markdeep/releases/tag/2.00).

So, I use DeepSeek-v4.1-Flash-1017 to vibe-coding this new `latex-theme-v2.js`.

## Usage

To use it, download `latex-theme-v2.js` and add this to the head of file:

```
<meta charset="utf-8">
<script src="./latex-theme-v2.js"></script>
<script src="https://morgan3d.github.io/markdeep/2/latest/markdeep2.min.js" markdeep="2"></script>
<plaintext>
```

Details can be found in `example.md.html`.
