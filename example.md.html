Here I just show its appearance. ### Footnote example A footnote example [^mailto]. The grammar is `[^mailto]`, where `mailto` is the label to cite. [^mailto]: abc@mail.def.cn (Here is where the footnote placed.) ### Equation example ```latex \begin{equation} \mu(I) = \mu_s + \frac{\mu_d - \mu_s}{I_0 + I} I, \quad\text{with } I = \frac{\dot{\gamma} d_p}{\sqrt{p / \rho_p}}, \label{eqn:muI_rheology} \end{equation} ``` The above source code would be rendered by mathjax as below \begin{equation} \mu(I) = \mu_s + \frac{\mu_d - \mu_s}{I_0 + I} I, \quad\text{with } I = \frac{\dot{\gamma} d_p}{\sqrt{p / \rho_p}}, \label{eqn:muI_rheology} \end{equation} The equation reference processed by mathjax (using `\eqref{muI_rheology}` command). -- Eq. \eqref{eqn:muI_rheology}. ### Adding caption A line directly below a block of one of these types is its caption: ``` [Figure [label]: Caption] [Table [label]: Caption] [Listing [label]: Caption] ``` A figure is a diagram or an image. Figures, tables, and listings are each numbered in document order, starting at 1 ### Table example This is the definition of a table with citing label `DEM_param` . The heading 2 (`##`) corresponds to `\section{}`, heading 3 (`###`) corresponds to `\subsection{}`, and so on. If a section do not need numbering, please use `(##) title`. ### Use `<figure>` as container. This is the definition of image (with citing label `fig_test1`): ``` ![Figure [fig_test1]: Test fugure 1.](lena.jpg) ``` The render result is: ![Figure [fig_test1]: Lena figure.](lena.jpg) The image can be referred by `Figure [fig_test1]`, or manually writtern as `[Fig. 1](#fig_test1)` -> [Fig. 1](#fig_test1). ### Citation The simple citation feature is implemented by citation.js. Here is an example: <bib-cite>smith2024, jones2023</bib-cite>, whose syntax is listed below, ``` <bib-cite>smith2024, jones2023</bib-cite> ``` Write the citation keys inside `<bib-cite>`, separated by commas (spaces or semicolons work too). A single key is written as `<bib-cite>smith2024</bib-cite>`.
